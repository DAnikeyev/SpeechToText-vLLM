# Changelog

## [1.0.3] - 2026-06-23

### Fixed
- Swapped the default `Right Ctrl` single-hold and triple-press-then-hold behaviors.
- `Right Ctrl` single hold now skips the LLM and inserts/copies the raw Whisper transcript.
- `Right Ctrl` triple-press then hold now runs the normal cleanup path and inserts/copies the cleaned transcript.

### Documentation
- Added explicit `Backspace` cancellation documentation to the hotkey/help text.
- Updated the README and About text so the shipped hotkey descriptions match the app behavior.
